# Eurodrone

A drone learning project targeting **300+ km/h forward airspeed**, with **piloted FPV flight for the first iteration**. The target is repeatable, approximately level powered flight; it is not a claim of demonstrated performance.

Design our own flight controller (FC), power distribution unit (PDU), primary structure/aerodynamic packaging, and harnesses. Use proven commercial components where they preserve the learning objectives, including pilot equipment, radio/video modules, propulsion components, and batteries, plus mature open-source stabilization firmware.

# Current Status
- The repository is at the requirements stage; no measured aircraft performance is recorded.
